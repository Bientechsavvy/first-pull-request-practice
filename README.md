# First Pull Request Practice 🚀

A safe, beginner-friendly repository for learning **Git and GitHub** by doing. Made for the MLH Global Hack Week "Beginner's Week" stream: *Your First Pull Request: Git & GitHub from Zero*.

Note : Nothing you do here can break anything. Mistakes are part of the lesson.

## Who is this for?
Complete beginners. You only need a free [GitHub account](https://github.com/signup) and a web browser. Installing Git on your computer is optional.

## What you will do
1. **Fork** this repository (your make own copy).
2. **Clone** it (or edit in the browser).
3. Create a **branch**.
4. Add your file to the `about-me/` folder.
5. **Commit** and **push** your change.
6. Open a **pull request** and watch it get merged.

Full step-by-step instructions are in [CONTRIBUTING.md](CONTRIBUTING.md). Need the commands? See the [cheat sheet](CHEAT_SHEET.md).

## Stuck?
- Open an **issue** and tag it `help wanted`.
- Ask in the MLH Community Discord, in the "stuck?" thread.
- Read the [GitHub Skills "Introduction to GitHub" course](https://skills.github.com).

## Code of conduct
Be kind. Everyone here is learning. Help each other, and never make anyone feel bad for asking a question.
